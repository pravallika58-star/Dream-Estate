# 🏡 Dream Estate – Find Your Perfect Home

## 🌟 About the Project

**Dream Estate** is a modern and elegant real estate property listing website designed to help users explore different properties and find their dream homes.

The website provides an attractive platform to showcase residential properties with images, prices, locations, property specifications, and facilities.

It features a professional user interface with a luxury color combination and organized sections to provide a smooth browsing experience.

## 🎯 Project Objective

The main objective of this project is to design and develop an attractive real estate website using HTML and CSS.

This project demonstrates the use of web development concepts such as webpage structure, styling, layouts, property cards, navigation, and responsive design techniques.

## ✨ Features

- **Modern Navigation Bar:** Easy navigation between different website sections.
- **Hero Section:** Attractive homepage with a background property image.
- **Property Search Section:** Search interface with location, property type, and price options.
- **Featured Properties:** Six property cards displaying property information.
- **Property Images:** Attractive images to showcase different properties.
- **Property Details:** Displays property descriptions and specifications.
- **Facilities and Amenities:** Shows available facilities of properties.
- **Interior Gallery:** Displays interior images of a featured property.
- **Why Choose Us:** Highlights five important features of the website.
- **About Us:** Provides information about the real estate platform.
- **Contact Section:** Includes contact information and an inquiry form.
- **Footer:** Contains website information and navigation links.

## 🎨 Design and Styling

The website follows a modern luxury theme.

**Color Palette:**
- Deep Navy Blue – Professional appearance.
- Gold – Luxury and elegance.
- White – Clean and simple layout.
- Light Grey – Background and content sections.

**Typography:**
- Playfair Display – Headings.
- Poppins – Body text.

## 🛠️ Technologies Used

- **HTML5:** Used to create the structure of the website.
- **CSS3:** Used for styling, layouts, colors, animations, and visual design.
- **Google Fonts:** Used for attractive typography.
- **Font Awesome:** Used for icons.
- **Unsplash:** Used for property and interior images.

## 🚀 How to Run the Project

Follow these steps to run the website:

1. Open the GitHub repository.
2. Download or clone the project.
3. Extract the downloaded files.
4. Open the project folder in Visual Studio Code.
5. Open `dream_estate_find_your_perfect_home.html`.
6. Run the HTML file using a web browser or Live Server.
